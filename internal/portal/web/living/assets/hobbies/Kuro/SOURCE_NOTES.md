# Kuro 鏡のポーズ素材 v1
現行 LIVING kuro-front.webp と腕組み基準原画を参照。コード・設置変更なし。

## 内容
png/: 生成原画。aligned/: 透過320×320 PNG。manifest.json: 衣装・ポーズ・段階・一様倍率・基準位置。Kuro_pose_layers.ora: 編集用ポーズレイヤー原本（線画/塗り/パーツ分離ではなく各姿勢の統合ラスターレイヤー）。一覧画像は確認用白背景、実素材背景は透過。

## 基準と再生
足元y=318、支持幅中心x=160、可視高さ300pxに縦横比を保った拡縮と移動。静止姿勢を切り替えて活動を示す構成。開始check → crossed / hip / faceを任意の順で保持・切替 → satisfied終了。滑らかな姿勢間の中割りや鏡像は未制作。追加ポーズは同じ名称/基準位置で増やせる。

## 留意点
顔・衣装の金細工・装飾形状には生成による微差が残る。輪郭周辺に微小半透明画素が残る。全身一様変換だけでは頭/身体各パーツの完全一致を保証しない。鏡の向き・家具遮蔽・画面上の実縮尺は配置側での確認が必要。素材へ家具や文字は描いていない。
