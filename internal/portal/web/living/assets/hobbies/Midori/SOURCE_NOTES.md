# Midori 読書素材 v1
現行 LIVING midori-front.webp の外見と読書基準原画を参照。金眼鏡・灰緑系ボブ・白緑の花衣装。緑無地本。非性的な読書の楽しさを表情で表現。本文、実在作品名、吹き出し、家具は描いていない。

## 内容
png/:生成原画、aligned/:透過320×320 PNG、manifest.json:素材/段階/一様倍率/足元基準、確認一覧、Midori_pose_layers.ora:姿勢別統合ラスターレイヤー。線画/塗り/身体パーツ分離ではない。

## 再生と設置
open開始 → read → page → read（読書ループ）、smileで喜び → hug終了。中割りや実際の肩揺れ動画は未制作。足先の下端をy=318、横中心をx=160へ整列、可視高さ300px。座面の暫定目安はx180,y225付近。ただし臀部はスカートで隠れ、家具への接地は未検証。既存椅子/ベッドの座面高さに合わせた配置調整が必要。鏡・机等を含むコードや配置は変更していない。

## 制限
衣装の花飾りや裾・眼鏡の細部には生成差があり、外周の微小半透明色粒が残る。全体拡縮/移動だけでは各身体部位の完全一致は保証しない。机と本/腕の前後関係は配置側で別途確認。座面と足元を同時に厳密固定する条件は未達で、現状は静止画切替の確認用素材。
