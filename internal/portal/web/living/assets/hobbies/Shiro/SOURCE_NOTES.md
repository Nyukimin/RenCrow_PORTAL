# Shiro 運動素材：白スラックス版

最新の本人指示を優先：上半身裸、いつもの白のスラックス、素足。紺ショーツ案と白コート付きストレッチ案は不採用・同梱しません。

既存LIVINGの顔・淡紫髪・青い目・眼鏡なし・SD頭身を維持し、ボディビルのポージング、ダンベル、プッシュアップを描きます。可動小物のダンベルは人物素材に含め、大型機材・床・家具・文字は含めません。

原画を保持し、許可された数値的拡縮/移動で共通キャンバスと支持点を整列。伏せ姿勢を立位の高さへ引き伸ばしません。編集原本はポーズ単位のラスタレイヤーで、線画/塗り/パンツの分離データではありません。

コード変更・配置は含みません。具体的な完成ファイル・検証値はmanifestを参照。

## 検証と制限
- 白スラックス版だけを収録。立位の一様倍率は0.261324、腕立ては原画で頭が大きく描かれたため0.225。縦横比は維持。
- 320×320 RGBA、最も手前の足/手の接地点をy=318へ移動。腕立ては手・つま先全ての位置が完全固定ではなく、ループに数pxの滑りが残る。厳密な固定は未達。
- 肌/白布/髪の細部は生成差分による揺れがあり、輪郭周囲の微小な半透明画素も残る。既存画面への配置検証は行っていない。
- 開始=ダンベル下位置、活動=上位置/ダブルバイセップス/腕立て上下、終了=立位で息を整える。立位から床へ移動する中間動作、ダンベルを置く動作は未制作。静止画差し替え用であり、滑らかな全身アニメーション完成品ではない。
- ORAはポーズごとに統合済みのラスターレイヤー。線画/塗り/身体パーツ別の元データではない。png/に生成原画を保持。
- 推奨再生順: dumbbell-low → dumbbell-high → dumbbell-low（反復）、pushup-up → pushup-down → pushup-up（反復）。終わりにendへ切替。基準はmanifest.json。
