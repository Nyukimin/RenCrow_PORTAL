# PORTAL Chat 会話枠スクロール仕様

対象 URL: `/?mode=chat`

## 目的

Chat画面の会話枠は、初回表示時と自動追従中の新着メッセージで最下行を表示する。一方、利用者が過去の会話を読むためにスクロール位置を移動した場合は、その位置を維持する。

## 表示契約

1. Chat画面を最初に描画したとき、会話枠は最下行を表示する。
2. 会話枠が最下行付近にあり自動追従中の場合、新着メッセージ追加後も最下行を表示する。
3. 利用者が最下行から離れてスクロールした場合、自動追従を停止し、利用者が移動したスクロール位置を維持する。
4. 利用者が会話枠を再び最下行付近までスクロールした場合、自動追従を再開する。
5. 自動追従の判定には24pxの許容誤差を設ける。画面サイズ（横1920x1080、縦1179x2556）による表示プロファイルが変わっても、この契約は変わらない。

## 実装境界

- 会話枠 `#chat` の `scroll` イベントで、自動追従中かどうかを更新する。
- メッセージ追加時は、自動追従中の場合だけ最下行へ移動する。
- 利用者が手動で移動した位置へ戻る処理は行わない。
